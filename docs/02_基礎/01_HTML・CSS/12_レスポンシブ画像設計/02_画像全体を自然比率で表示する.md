# 02_画像全体を自然比率で表示する

画像の端まで見せ、画像自身の縦横比を保ったまま大きさを調整する場合は、別の比率を持つ表示枠を作らない。

```text
CSSで決める       → 表示する幅
画像自身に任せる → その幅に対応する高さ
```

ロゴ、バッジ、人物写真などで、内容を切らずに大きさだけ変えたいときに使う。先に決めた形の領域へ収めたい場合は、[決めた表示領域に画像を合わせる](./03_決めた表示領域に画像を合わせる.md)へ進む。

## 最小の実装

```html
<img
  class="image"
  src="./img/dog.jpg"
  alt="芝生に座っている犬"
  width="600"
  height="400"
>
```

```css
.image {
  display: block;
  max-width: 100%;
  height: auto;
}
```

- `max-width: 100%`は、画像が親より大きいときに表示幅を縮める
- `height: auto`は、表示幅に対応する高さを画像自身の比率から決める
- `display: block`は、行内画像のベースラインに由来する下側の隙間を避ける
- HTMLの`width`・`height`属性は画像の寸法と比率を伝える。画像ファイルと対応する値を使う

画像をさらに小さくしたい場合は、必要な対象の`width`や`max-width`を調整する。部品全体の幅を変えるのか、`img`だけを変えるのかはHTMLの構造と配置方法も含めて決める。

## widthとmax-widthを使い分ける

画像を自然幅より拡大するかどうかで、`width: 100%`と`max-width: 100%`を使い分ける。これはGridに限らず、画像の幅の制御の話。

ここでは通常フローの親の中に画像を置き、画像にHTMLの寸法属性や別の幅・高さの指定を加えない。`width`が`auto`の画像を基準に比較する。`100%`の基準は、この例では親の内容幅になる。

| 指定 | 動作 |
| --- | --- |
| `width: 100%` | 親の内容幅に合わせる。親が自然幅より広ければ、画像を拡大する |
| `max-width: 100%` | 自然幅を基本に、親より大きければ縮小する。親が広いだけでは拡大しない |

### 同じ画像で比べる

自然幅240pxの画像を、内容幅480pxの親へ入れる。画像ファイルがその自然幅を持つことを確認して使う。

```html
<div class="frame">
  <img class="image" src="./img/scene.jpg" alt="風景">
</div>
```

```css
.frame {
  width: 480px;
}

.image {
  max-width: 100%;
  height: auto;
  display: block;
}
```

この状態なら、画像の表示幅は240px。`max-width: 100%`は上限を480pxにしているだけなので、自然幅240pxの画像を480pxへ広げる指定にはならない。

親の幅と画像を変えず、画像へ`width: 100%`だけを追加する。

```css
.image {
  width: 100%;
}
```

画像の表示幅は480pxになり、自然幅より拡大する。`max-width: 100%`が残っていても、その範囲内の幅への拡大は止めない。

| 親の内容幅 | `max-width: 100%`だけ | `width: 100%`を追加 |
| --- | --- | --- |
| 480px | 240px：自然幅のまま | 480px：親幅まで拡大 |
| 150px | 150px：親幅まで縮小 | 150px：親幅に合わせる |

画像をカード幅いっぱいに広げたいときは`width: 100%`を使う。自然幅より大きくせず、親より大きいときだけ縮めたいなら`max-width: 100%`を使う。

`max-width`自体は幅の上限を決める指定であり、画像の幅を常に自然幅へ戻す指定ではない。HTMLの`width`属性や別のCSSで幅が指定されていれば、その指定も含めて判断する。

### Gridとの関係

Gridの列幅の計算と、画像サイズの計算は別。画像がGridアイテムの中にあるなら、列幅と画像の間にGridアイテムの幅もある。列が親に収まっていても、固定幅の子や画像がその幅を超えている場合がある。

どの対象を調整するかは、[列幅と子要素のサイズの違い](../09_レイアウト/Grid/10_列幅と子要素のサイズの違い.md)で確認する。

## `aspect-ratio`を重ねる必要はない

画像自身の比率で表示するだけなら、同じ比率をCSSの`aspect-ratio`でもう一度指定する必要は基本的にない。画像自身の比率とは別に表示領域を決めたい場合は、[決めた表示領域に画像を合わせる](./03_決めた表示領域に画像を合わせる.md)へ進み、比率で作るか高さを指定するか選ぶ。

自然比率で表示するときは、通常`object-fit: cover`も必要ない。画像を切らずに見せることと、別の枠の中で`contain`を使って全体を見せることは別の設計である。

## 確認すること

1. DevToolsで`img`の表示幅と高さを確認する。
2. 幅を変えたとき、高さも画像自身の比率に沿って変わるか確認する。
3. `max-width`と`height: auto`が意図した要素へ適用されているか確認する。
4. 上の比較では、親が480pxのとき、`max-width: 100%`だけなら240px、`width: 100%`を加えたら480pxになることを確認する。親を150pxへ変えると両方150pxになる。

HTMLの寸法属性による読み込み前の領域予約は、[画像の読み込み前に表示領域を予約する](../11_メディアの表示枠と重ね配置/03_画像の読み込み前に表示領域を予約する.md)で扱う。`img`と背景のどちらで使うか決まっていない場合は、[imgとbackground-imageを選ぶ](../10_画像と背景/02_imgとbackground-imageを選ぶ.md)へ戻る。

## このページのまとめ

- 画像自身の比率を保つときは、表示幅を決めて`height: auto`で高さを任せる。
- 別の寸法指定がない`width: auto`の画像では、`max-width: 100%`は自然幅より大きくせず、親より大きいときだけ縮める。
- 親の幅いっぱいに広げるときは`width: 100%`を使う。
- `display: block`は、行内画像のベースラインに由来する下側の隙間を避ける。
