# 配置の基本で確認したいことから読む

要素を並べる前に、今の並び、配置する親、幅を制限する箱、余白を置く境界を確認したいときに読む。Flex・Gridのどちらでも使う考え方を、疑問に合わせて選ぶ。

## 確認したいことから選ぶ

| 確認したいこと | この記事で分かること | 読むページ |
| --- | --- | --- |
| 指定を増やす前の並びを知りたい | 通常フローを配置の比較基準にする | [通常フローを基準にする](./02_通常フローを基準にする.md) |
| FlexとGridのどちらを、どこへ指定するか迷う | 直下の子を並べる親と、配置方法の選択 | [FlexとGridで直下の子を並べる](./03_FlexとGridで直下の子を並べる.md) |
| 入れ子のFlex・Gridが重複に見える | 外側で配置される役割と、内側を並べる役割 | [親子のレイアウト文脈を区別する](./04_親子のレイアウト文脈を区別する.md) |
| 背景は画面幅、中身だけ一定幅にしたい | 全幅の外側と最大幅を持つ内側の分担 | [コンテンツの最大幅と左右余白を作る](./05_コンテンツの最大幅と左右余白を作る.md) |
| どの箱へ余白を書けばよいか迷う | 要素間、別ブロック間、枠と中身の区別 | [gapとmarginとpaddingを使い分ける](./06_gapとmarginとpaddingを使い分ける.md) |
| 縦marginが足し算にならない | 相殺が起きている場所の確認 | [marginの相殺が起きる場所を確認する](./07_marginの相殺が起きる場所を確認する.md) |

全部を順に読む必要はない。marginの相殺も、その挙動で困ったときに戻ればよい。

配置方法を決めたら、[Flexの位置と幅](../03_Flex/01_Flexで調整したいことから読む.md)、または[Gridの列・行・配置](../04_Grid/01_Gridはどんなレイアウトで使う.md)へ進む。
