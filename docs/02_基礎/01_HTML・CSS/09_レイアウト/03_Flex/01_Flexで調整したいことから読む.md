# Flexで調整したいことから読む

Flexで子を並べた後、位置を揃えたいのか、使う幅を分けたいのかで読む先を選ぶ。

## 調整したいことから選ぶ

| 調整したいこと | 確認すること | 読むページ |
| --- | --- | --- |
| 子全体を中央・端へ寄せたい。一つの子だけ右や下へ送りたい | 主軸と交差軸、全体と一つの子の違い | [Flexで子の位置を揃える](./02_Flexで子の位置を揃える.md) |
| サイドは固定し、メインだけ残り幅を使いたい | 固定側・可変側・縮んでよい側の役割 | [Flexで固定幅と可変幅を組み合わせる](./03_Flexで固定幅と可変幅を組み合わせる.md) |

FlexとGridの選択から確認したい場合は、[直下の子を並べる方法](../02_配置の基本/03_FlexとGridで直下の子を並べる.md)へ戻る。

配置を作れたら、幅を変えて確認し、必要に応じて[配置が成立する幅からブレークポイントを決める](../05_配置が成立する幅でブレークポイントを決める.md)。
