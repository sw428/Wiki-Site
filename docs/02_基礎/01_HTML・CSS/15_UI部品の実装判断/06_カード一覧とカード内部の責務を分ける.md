# 06_カード一覧とカード内部の責務を分ける

カード一覧では、一覧親、カード、画像枠、本文を別の箱として考える。

## 一覧親

```css
.list {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  gap: 30px;
}
```

列数とカード同士の間隔は一覧親が担当する。どの要素がGridアイテムなのかを確認し、機械的に`height: 100%`を足さない。

同じ行のカードはGridアイテムとして行の高さまで伸びる。カードとの間に`li`やリンクを挟む場合は、実際に伸びる要素と、同じ高さにしたい箱を確認し直す。

## カード内部

```html
<div class="list">
  <article class="card">
    <a class="media" href="#">
      <img src="thumb.jpg" alt="記事を読む" width="800" height="600">
    </a>
    <div class="body">
      <h3 class="title">記事タイトル</h3>
      <p class="text">説明文</p>
      <p class="date">2026.06.22</p>
    </div>
  </article>
</div>
```

```css
.media {
  display: block;
  aspect-ratio: 4 / 3;
}

.media > img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

- カード間隔: 一覧親
- 画像比率: メディア枠
- 文章: 本文箱
- リンク範囲: HTMLの意味から決める

この例の画像リンクは画像だけを内容に持つため、`alt`でリンク先の目的を伝える。画像と目的を説明する文字を同じ`a`へ含める場合は、その文字だけで目的が分かるなら画像の`alt=""`を検討できる。カード全体をリンクにするときは、その中へ別のリンクやボタンを入れない。

一覧の並べ方は[レイアウトで調整したいことから読む](../09_レイアウト/01_レイアウトで調整したいことから読む.md)、画像枠は[比率で表示領域を作る](../12_レスポンシブ画像設計/04_比率で表示領域を作る.md)へ戻る。

## 親幅に合わせて列数が変わるカード一覧を作る

列数・列幅・gap・行高を組み合わせて、広いときは3列、狭いときは2列・1列へ変わるカード一覧を作りたい。各カードは文章量が違ってもよい。**どのCSSを親・子・中身へ書けばよいだろう？**

親は列と間隔、カードは内側の余白、文章は見出しとの距離と折り返しを担当する。

```html
<ul class="list">
  <li class="card">
    <h3 class="title">HTML</h3>
    <p class="text">内容の意味と構造を記述する。</p>
  </li>
  <li class="card">
    <h3 class="title">CSS</h3>
    <p class="text">見た目と配置を指定する。文章を増やし、同じ行のカードの高さも比べる。</p>
  </li>
  <li class="card">
    <h3 class="title">JavaScript</h3>
    <p class="text">操作に応じた動きを作る。</p>
  </li>
  <li class="card">
    <h3 class="title">Grid</h3>
    <p class="text">複数行で列の位置をそろえる。</p>
  </li>
  <li class="card">
    <h3 class="title">Flex</h3>
    <p class="text">一方向の並びを調整する。</p>
  </li>
  <li class="card">
    <h3 class="title">画像</h3>
    <p class="text">内容に合う表示枠を考える。</p>
  </li>
</ul>
```

```css
.list {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(min(100%, 150px), 1fr));
  gap: 30px;
  margin: 0;
  padding: 0;
  list-style: none;
}

.card {
  padding: 20px;
  background: #cfe4ff;
}

.title {
  margin: 0 0 10px;
}

.text {
  margin: 0;
  overflow-wrap: anywhere;
}
```

親のmargin・padding・list-styleは`ul`の初期表示を整える補助指定。背景色はカードを見分けるために使う。`overflow-wrap: anywhere`は、長いURLなど通常は切れにくい文字も含む場合の備えで、文字を小さくする指定ではない。

列の下限150pxとgap30pxは[Gridの自動列数の比較](../09_レイアウト/04_Grid/05_列数を自動変更するには.md#親の幅だけを変えて比べる)とそろえている。親の内容幅を540px・390px・210pxへ変えると、短い内容が収まる条件で3列・2列・1列になる。さらに広げると4列以上になるため、「常に最大3列」という指定にはならない。画面幅ごとに列数を固定する条件は同記事のメディアクエリの例と区別する。

`min(100%, 150px)`は親が150px未満の場合も下限を親の幅まで下げる指定。ただし子のpaddingや長い文字など、中身が極端な狭さへ必ず収まることまでは保証しない。[列・子・中身の寸法](../09_レイアウト/04_Grid/10_列幅と子要素のサイズの違い.md)を分けて確認する。

行高は指定せず、内容に応じて決める。同じ行の長文カードに合わせて行が高くなり、直下の各カードも通常はその行へ伸びる。最低高が必要な場合は[行高のauto・固定高・minmaxの比較](../09_レイアウト/04_Grid/07_行の高さはどう決まる.md#内容に合わせる行と固定した行を比べる)へ進む。行ごとの高さが同じになる保証や、カード内部の末尾の位置がそろう保証はない。末尾の配置は[可変本文と下寄せ要素](./07_カードの可変本文と下寄せ要素を両立する.md)で扱う。

親幅を変えた後は、2枚目の文章を増やし、行の境界とカードの箱を比べる。カード内の余白だけを変えるときは`.card`、見出しと本文の距離なら`.title`を触り、一覧親のgapとは分けて確認する。
