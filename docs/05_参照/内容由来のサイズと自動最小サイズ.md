# 内容由来のサイズと自動最小サイズ

Gridで「内容の最小幅が列幅に影響する」ときに、何を基準にした幅なのかを確認するためのカード。

## 用語と役割

| 概念 | 意味 |
| --- | --- |
| Intrinsic Sizing（内在的サイズ計算） | 内容に基づくサイズ計算 |
| `min-content` | 通常の改行可能な位置で可能な限り折り返したときに必要な最小幅。ここでは横書きの幅として考える |
| Automatic Minimum Size（自動最小サイズ） | `min-width: auto`などで、レイアウトの条件によって内容などから決まる最小サイズ |

## min-contentの具体例

以下は通常の折り返しを使い、別の幅・高さ・最小幅・最大幅の制約を加えていない場合の目安。

| 内容 | 最小幅を考える目安 |
| --- | --- |
| 英語 | 通常の折り返しなら、最も長い単語の幅が目安 |
| 日本語 | 文字間で折り返せるため、比較的小さくなる場合がある。禁則処理などの影響は受ける |
| 画像 | 自然幅を持つ画像では、基本的に自然幅が基準 |

自動最小サイズは、常に`min-content`と同じになるわけではない。Gridでは、子の`overflow`や、またぐ列の最小値・可変列の有無などの条件によって、内容由来の最小幅を使うかどうかが変わる。

子の自動最小幅が列へ影響する関係は、[列と子の最小幅を分ける](../02_基礎/01_HTML・CSS/09_レイアウト/04_Grid/10_列幅と子要素のサイズの違い.md#列と子の最小幅を分ける)で確認する。通常の`1fr`から`minmax(0, 1fr)`へ変える目的は、[1frなのに列が広がるのはなぜ？](../02_基礎/01_HTML・CSS/09_レイアウト/04_Grid/04_1frなのに列が広がるのはなぜ.md)で扱う。

仕様確認先：[CSS Sizing — Auto Box Sizes](https://www.w3.org/TR/css-sizing-3/#auto-box-sizes)、[CSS Grid — Automatic Minimum Size of Grid Items](https://www.w3.org/TR/css-grid-2/#min-size-auto)。
